# 시리즈 인터랙션 의사결정

**상태:** 채택됨
**갱신일:** 2026-07-27
**기계 판독용 레지스트리:** [`series-interaction-decisions.yaml`](./series-interaction-decisions.yaml)

## 목적

이 문서는 공개 서가의 시리즈 책 팝업에 적용한 인터랙션 결정을 사람이 읽기 쉽게 설명합니다. 정확한 수치, 제스처 범위, 검증 사실은 YAML 레지스트리를 기준으로 합니다.

## 사용자 경험 원칙

1. **모션은 장식이 아니라 피드백이다.** 상태, 결과, 경계를 알려야 합니다.
2. **책 상세 전체를 움직이지 않는다.** 권 변경 시 커버·제목·메타데이터를 함께 이동하지 않아 깜빡임과 멀미를 피합니다.
3. **제스처는 명확히 분리한다.** 팝업 권 이동과 시리즈 표지 Slider는 별도 조작입니다.
4. **크롬만 숨기고 기능은 남긴다.** 스크롤바를 숨겨도 스크롤·터치패드·드래그는 유지합니다.
5. **모션 감소를 존중한다.** 관성 및 장식적 모션은 즉시 상태 변경으로 대체합니다.

## 구성 요소

### 팝업 권 이동

시리즈 표지 Slider 영역을 제외한 팝업 어디에서든 가로 드래그 또는 터치패드 Swipe로 현재 권을 변경합니다. 48px 드래그 또는 `0.5px/ms` 해제 속도를 넘겨야 하며, 성공한 권 변경 뒤에는 중복 전환을 막기 위해 220ms 잠금을 둡니다.

첫 권과 마지막 권에서는 이동 불가 요청을 무반응으로 두지 않고 진행 방향으로 10px 짧게 밀었다가 복귀합니다. 경계 상황에서만 허용하는 상세 영역 모션입니다.

### 이동 화살표

이전·다음 화살표에는 Reicon `angles-left`, `angles-right` 경로를 인라인 24px SVG로 사용합니다. 각 화살표는 44px 원형 터치 영역을 가지며, 300ms 무반동 스프링·3px 호버 이동·`0.96` 탭 축소처럼 국소적인 피드백만 제공합니다. 화살표 드래그는 팝업 Swipe 처리에서 제외해 클릭 한 번이 두 권 이동으로 이어지지 않게 합니다.

### 시리즈 표지 Slider

Slider는 표지 전용 가로 목록입니다. 선택된 표지에는 2px 초록 라인만 표시하며, 권수 텍스트·카드 테두리·목록 이동 버튼은 의도적으로 사용하지 않습니다.

드래그와 터치패드 가로 휠은 목록만 움직이고 현재 책을 바꾸지 않습니다. Slider는 request-animation-frame 렌더링, 해제 속도 기반 관성, 끝 경계 저항, 가장 가까운 표지 위치 스냅을 사용합니다. 휠 피커의 **조작 감각만** 참고하며 3D 드럼 시각 효과는 적용하지 않습니다.

### 권 선택 뒤 상단 복귀

팝업 하단에서 다른 권을 선택하면 콘텐츠를 220~280ms로 제한한 ease-in-out 모션으로 상단에 복귀시킵니다. 포인터 다운 또는 세로 휠 입력은 이 복귀를 즉시 취소해 독자의 조작을 우선합니다. 모션 감소 설정에서는 즉시 상단으로 이동합니다.

### 스크롤바

팝업의 가로·세로 스크롤바는 숨깁니다. 콘텐츠 스크롤과 Slider의 가로 드래그·터치패드 동작은 그대로 유지합니다.

## 피드백에서 나온 결정

| 불편 피드백 | 결정 |
| --- | --- |
| 팝업 양 끝에서만 권 이동이 가능했다. | Slider를 제외한 팝업 전체로 권 이동 범위를 확장한다. |
| Slider 드래그와 팝업 Swipe가 충돌할 수 있었다. | Slider 섹션을 명확한 제스처 경계로 둔다. |
| 권수·테두리·목록 버튼이 시리즈 목록을 복잡하게 만들었다. | 표지 전용 목록과 하나의 초록 선택 라인만 사용한다. |
| 첫·마지막 권에서 무반응처럼 보였다. | 절제된 방향성 경계 피드백을 제공한다. |
| 상세 전체 이동·페이드·빈 프레임이 불편하고 멀미를 유발했다. | 상세 전체 이동 및 페이드 전환을 제거한다. |
| 긴 입력 잠금이 뚝뚝 끊기는 느낌을 만들었다. | 성공한 권 변경을 220ms의 짧은 잠금으로 제한한다. |
| 하단에서 권 선택 시 상단으로 즉시 점프했다. | 취소 가능한 상단 복귀 모션을 사용한다. |
| 스크롤바가 시각적 잡음을 만들었다. | 스크롤 기능을 유지하며 숨긴다. |

## 가드레일

- 권 변경 시 상세 전체 이동이나 페이드를 다시 도입하지 않습니다.
- Slider 드래그나 가로 휠로 권을 선택하지 않습니다.
- 팝업 스크롤바를 다시 노출하지 않습니다.
- 조작 감각만 필요한 경우 외부 컴포넌트의 3D 시각 표현을 복제하지 않습니다.
- 수치·타이밍·제스처 범위는 YAML 레지스트리를 단일 기준으로 사용합니다.

## 검증

인터랙션 테스트는 시리즈 그룹화, Slider/팝업 제스처 분리, Slider 스냅, 경계 피드백, 상단 부드러운 복귀, 스크롤바 숨김을 다룹니다.

```sh
npm run build
npm run test:e2e
```

기록 기준점은 성공한 빌드와 **Playwright 테스트 21건 통과**입니다.
